# 📂 iOS Project Structure Guide

## Folder Overview

```
fuel-user-dev/
├── capacitor.config.ts          ← Main Capacitor configuration
├── package.json                 ← npm scripts for iOS builds
├── ios/                         ← iOS native project (generated by Capacitor)
│   └── App/
│       ├── App.xcworkspace      ← OPEN THIS FILE in Xcode ⚠️
│       ├── App.xcodeproj        ← Don't open this!
│       ├── Podfile              ← CocoaPods dependencies
│       └── App/
│           ├── Info.plist       ← iOS app permissions & config
│           ├── AppDelegate.swift
│           └── Assets.xcassets  ← App icons, splash screens
├── dist/                        ← Built web assets (after npm run build)
└── Documentation/
    ├── TESTFLIGHT_SETUP.md      ← Complete setup guide
    ├── QUICKSTART_IOS.md        ← Quick reference
    ├── TESTFLIGHT_CHECKLIST.md  ← Step-by-step checklist
    ├── TESTFLIGHT_SUMMARY.md    ← Handover summary
    └── Info.plist.template      ← Info.plist template
```

## Key Files Explained

### `capacitor.config.ts`
**What it does**: Main configuration for Capacitor
**Important settings**:
- `appId`: Bundle identifier for App Store (`com.fuelfriend.app`)
- `appName`: Display name (`Fuel Friend`)
- `webDir`: Where built web files go (`dist`)
- `plugins`: Plugin configurations (Google Auth, SplashScreen)

**When to edit**: 
- ✅ Changing bundle ID
- ✅ Adding new plugins
- ✅ Modifying Google Sign-In

---

### `package.json`
**What it does**: Contains npm scripts for building iOS app

**Key scripts**:
```json
"ios:build": "Build web + sync to iOS",
"ios:open": "Open Xcode workspace",
"ios:run": "Run on device/simulator",
"testflight:prepare": "Full build + sync for TestFlight"
```

**When to use**:
- ✅ Building for TestFlight: `npm run testflight:prepare`
- ✅ Opening Xcode: `npm run ios:open`
- ✅ Testing: `npm run ios:run`

---

### `ios/App/App.xcworkspace` ⚠️ CRITICAL
**What it is**: Xcode workspace file (includes CocoaPods)
**IMPORTANT**: ALWAYS open `.xcworkspace`, NOT `.xcodeproj`!

**Why**: 
- `.xcworkspace` includes pods (dependencies)
- `.xcodeproj` alone will cause import errors

**How to open**:
```bash
npm run ios:open
# OR manually:
open ios/App/App.xcworkspace
```

---

### `ios/App/Podfile`
**What it is**: CocoaPods dependency manager
**Auto-generated by**: `npx cap sync ios`

**Contents**:
```ruby
platform :ios, '15.0'  # Minimum iOS version

target 'App' do
  pod '@capacitor/ios', :path => '../../node_modules/@capacitor/ios'
  pod '@codetrix-studio/capacitor-google-auth', :path => '../../node_modules/@codetrix-studio/capacitor-google-auth'
  # ... other pods
end
```

**When to run `pod install`**:
- ✅ First time setup
- ✅ After adding new Capacitor plugins
- ✅ When pods are missing

---

### `ios/App/App/Info.plist` 🔑 CRITICAL
**What it is**: iOS app configuration and permissions

**MUST CONFIGURE**:
1. **Google Sign-In Client ID**
   ```xml
   <key>GIDClientID</key>
   <string>YOUR_IOS_CLIENT_ID.apps.googleusercontent.com</string>
   ```

2. **URL Schemes for Google**
   ```xml
   <key>CFBundleURLTypes</key>
   <array>
     <dict>
       <key>CFBundleURLSchemes</key>
       <array>
         <string>com.googleusercontent.apps.YOUR_REVERSED_ID</string>
       </array>
     </dict>
   </array>
   ```

3. **Permissions** (Already configured):
   - Camera (QR Scanner)
   - Photo Library (Image Upload)
   - Location (Maps)

**Template available**: See `Info.plist.template` in root folder

---

### `ios/App/App/AppDelegate.swift`
**What it is**: Main app entry point
**Capacitor handles**: Most of the setup automatically

**When to edit**: 
- ❌ Rarely needs modification
- Only for advanced native integrations

---

### `ios/App/App/Assets.xcassets`
**What it is**: App icons and splash screens
**Contains**:
- AppIcon.appiconset (App icon)
- Splash.imageset (Launch screen)

**To update app icon**:
1. Replace images in `Assets.xcassets/AppIcon.appiconset`
2. Or use Xcode's asset catalog editor

---

### `dist/` Folder
**What it is**: Built web application
**Generated by**: `npm run build`
**Synced to iOS by**: `npx cap sync ios`

**Contents**:
- index.html
- assets/ (JS, CSS, images)
- Other web assets

**Important**: 
- ✅ This folder is uploaded to App Store
- ✅ Must be rebuilt after any code changes
- ✅ Automatically synced to iOS by Capacitor

---

## Build Process Flow

```
1. Edit Code (TypeScript/React)
   ↓
2. npm run build
   ↓
3. Vite builds to dist/ folder
   ↓
4. npx cap sync ios
   ↓
5. Capacitor copies dist/ to ios/App/App/public/
   ↓
6. CocoaPods updates (if needed)
   ↓
7. Open Xcode → Archive → TestFlight
```

## Common File Operations

### Add New Capacitor Plugin
```bash
npm install @capacitor/plugin-name
npx cap sync ios
cd ios/App && pod install && cd ../..
```

### Update App Version
1. Edit `capacitor.config.ts`:
   ```typescript
   appId: 'com.fuelfriend.app',
   appName: 'Fuel Friend',
   ```
2. In Xcode, update version numbers in target settings

### Clean Build
```bash
npm run ios:clean
cd ios/App && pod deintegrate && pod install && cd ../..
npm run testflight:prepare
```

### Rebuild from Scratch
```bash
# Delete everything
rm -rf ios
rm -rf dist

# Recreate
npx cap add ios  # Only if ios folder deleted
npm run build
npx cap sync ios
cd ios/App && pod install
```

## Xcode Tips

### Opening the Project
✅ CORRECT:
```bash
npm run ios:open
# Opens: ios/App/App.xcworkspace
```

❌ WRONG:
```bash
# Don't open: ios/App/App.xcodeproj
# Will cause: "Module not found" errors
```

### Selecting Device
1. Click device dropdown in Xcode toolbar
2. Select your physical iPhone/iPad
3. OR select simulator for quick testing

### Building
- **Debug Build**: For testing on device/simulator
- **Release Build**: For TestFlight/App Store (Archive)

### Signing Issues
1. Go to project → App target → Signing & Capabilities
2. Toggle "Automatically manage signing" off/on
3. Select correct team
4. Check provisioning profile

## Troubleshooting

### "No such module" errors
**Solution**: Run `pod install` in `ios/App/` folder

### Changes not appearing
**Solution**: 
```bash
npm run build
npx cap sync ios
```

### Google Sign-In not working
**Check**:
1. iOS Client ID created in Google Cloud Console
2. Bundle ID matches exactly
3. `GIDClientID` in Info.plist
4. URL scheme in Info.plist (reversed client ID)

### App crashes on launch
**Check**:
1. Xcode console for error messages
2. All pods installed correctly
3. Info.plist has all required permissions
4. Google Sign-In properly configured
